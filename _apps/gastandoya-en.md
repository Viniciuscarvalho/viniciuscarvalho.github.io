## Overview

**GastandoYa** is an iOS app for **personal finance management**. It simplifies recording and analyzing expenses while offering deeper features when needed: goals, trends, integrations, and premium tools.

## Main features

- **Plan your future with statistics**: a clean dashboard showing monthly balance, income, expenses, spending by category, and trends.
- **Complete financial overview**: cash flow and insights with weekly, monthly, and yearly views.
- **Financial goals**: set a target amount and deadline, then track progress.
- **Secure synchronization**: local data with optional **iCloud** sync and automatic backups.
- **Spending analysis**: record transactions quickly and filter income and expenses.
- **Integrations**:
  - **Notion**: automatically import transactions from databases.
  - **CSV/PDF**: import statements and spreadsheets (Premium).

## Premium

Premium unlocks advanced features:

- CSV/PDF import and export
- PDF reports
- Smart rules and automation
- Backup and iCloud synchronization
- Notion integration
